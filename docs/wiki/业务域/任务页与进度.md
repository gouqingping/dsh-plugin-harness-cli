# 业务域：任务页与进度

> 所属域功能点：F3.1–F3.10。上游：初始化（生成目录与模板）。下游：规范文档（同一次创建）。

## 1. 能做什么

| 功能点 | 一段话 |
|---|---|
| F3.1 建任务页 | 一条命令给一个任务建「页面 + 四份文档」，并刷新总览页。 |
| F3.2 五段结构校验 | 页面必须按「领域 → 契约 → 用例 → 规划 → 记录」五段写全，缺哪段报哪段。 |
| F3.3 总进度与记录一致 | 总进度由步骤等权汇总，不手填；每一步变化（开始 / 完成 / 阻塞 / 改规划）立刻追加记录并更新页面，末条记录必须等于当前汇总。 |
| F3.4 总览页汇总 | 一张总览页列出所有进行中 / 待验收任务；过期即失败，一条命令重新汇总。 |
| F3.5 目录保留策略 | 任务目录太多时按最近更新时间保留，超出的可预览后清理。 |
| F3.6 UI 设计稿 | 需要界面时生成 antd v5 风格的设计稿与设计说明；省略任务名时自动选最近的任务。 |
| F3.7 方案确认与文档补全 | `plan` 一次补全四份规范文档、任务页区块与 `plan.html`，确认后才开工。 |
| F3.8 进度写入口 | 用一条命令改步骤 / 状态：自动追加进度记录、重算总进度、同步总览；每一步变化都调用，不攒到收工。 |
| F3.9 文档复盘 | Agent 复盘：核对 docs/specs 与任务页，写 review.md（含文档指纹），作为确认前提。 |
| F3.10 根目录任务总览 | `plans.html`：**点任务名弹窗看该任务的 `progress.html`**、展开/收起编辑四份文档、UI 弹窗预览、对话、删除、重跑；`--serve` 后总览每次请求都重新汇总，动作直接落盘。 |

## 2. 怎么触发

```sh
node <工具>/bin/dsh-plugin-harness-cli.js page login-flow --user-words "先把登录做了"

node scripts/prototype-check.js             # 只读检查
node scripts/prototype-check.js --sync      # 重新汇总总览页
node scripts/prototype-check.js --prune --dry-run
```

## 3. 页面五段（判定口径）

| 段 | 必须有什么 | 判定 |
|---|---|---|
| 1 领域（DDD） | 限界上下文、统一语言 ≥3 条、聚合/实体 ≥1、不变量 ≥1 | 缺项即失败 |
| 2 契约（SDD） | ≥2 条，每条六格：编号 / 契约 / 输入 / 输出 / 错误语义 / 验收标准 | 缺格或编号重复即失败 |
| 3 测试（TDD） | 每条用例挂在一条契约上，先红后绿；每条契约至少一条用例 | 悬空或无用例即失败 |
| 4 任务规划 | 步骤编号从 1 连续、可人工增删，每步绑定一条契约 | 断档或未绑契约即失败 |
| 5 进度记录 | 每一步变化都立刻追加一条，末条总进度 = 页面汇总 | 不一致即失败 |

## 4. 规则

1. **一任务一页**：新任务另建目录，不往旧页追加；旧页只加一句指向新页的链接。
2. **进度不手填、不攒**：每一步变化都立刻改步骤百分比并同步，总进度由页面脚本回写。
3. **100% 与「待验收」互斥**：真机/回归没验收完，不许标 100%。
4. **记录只追加**：时间递增，不删历史。
5. **总览不手改**：由汇总命令生成；手改会在下一次校验被判过期。
6. **状态三选一**：进行中 / 待验收 / 完成；标「完成」必须全部步骤 100% 且用例全绿。

## 5. 产出

```
prototype/progress.html            总览（进行中 / 最近完成）
prototype/<任务名>/progress.html    任务页
prototype/_template/progress.html   模板
scripts/prototype-check.js          页面校验与汇总脚本
```

## 6. 失败现象与处理

| 现象 | 含义 | 处理 |
|---|---|---|
| 新建页校验全红 | 页面还是骨架 | 填五段；这是设计，不是故障 |
| 总进度的数不对 | 手填了总进度 | 改成「—」，让脚本回写 |
| 「总览过期」 | 改了页面没汇总 | 跑一次汇总命令 |
| 「任务目录超过上限」 | 老页面堆积 | 先预览再清理 |
| 标「完成」被拒 | 还有步骤不到 100% 或还有红用例 | 补完或改成「待验收」 |
