# 功能清单

> 读者：所有人（查询入口）。本页回答「这套系统到底有哪些功能点」，并下钻到每个业务域。
> 口径来自实际命令与判定规则，不来自宣传语。

## 1. 功能点口径（先对齐再数数）

一条功能点 = **现场人员在界面上能完成的一件业务事**，或**系统按规则自动完成的一件业务事**。

- 本系统的「界面」是命令行与模型工具调用界面（没有图形后台），因此「一条命令完成一件业务事」即一条功能点。
- **同一能力在多个业务域复用时，只在能力所属域计一次**，其他域用链接说明关系。本文末尾列出复用关系。
- 不计入功能点：纯内部实现、模板文案、测试用例本身。

## 3. 功能点全表

### 3.3 任务页与进度（10）

| 编号 | 功能点 | 触发 | 完成标志 | 失败表现 |
|---|---|---|---|---|
| F3.1 | 建任务页 | `page <任务名>` | 页面 + 四份文档 + 总览刷新 | 任务名含空格或斜杠 / 页面已存在未加 `--force` |
| F3.2 | 五段结构校验 | `check`（任务页脚本） | 领域 / 契约 / 用例 / 规划 / 记录齐备且合法 | P13–P16 红项 |
| F3.3 | 总进度与进度记录一致 | 改步骤百分比 + 追加记录 | 末条记录 = 页面汇总 | P5 / P9 红项 |
| F3.4 | 总览页汇总进行中任务 | `--sync` | 进行中 / 待验收任务全部列出，数值一致 | 过期 → P11 红项 |
| F3.5 | 任务目录保留策略 | `--prune` | 超过上限的旧目录被清理（可先预览） | 超上限未清理 → P1 红项 |
| F3.6 | 生成 antd UI 设计稿 | `ui [任务名]`（省略=最近的任务） | `ui/` 下生成设计稿与说明，并同步 `design.md` 的 UI 摘要与指纹 | 非 antd 体系 → P20；设计稿变了没同步 → P23 |
| F3.7 | 方案确认与文档补全 | `plan [任务名] [--confirm --by <人>]` | 四份规范文档 + 任务页区块 + plan.html 一次补全；确认后状态「已确认」 | 缺方案 / 未确认就推进度 → P21 红项，progress 拒绝 |
| F3.8 | 进度写入口 | `progress <任务名> --step N --pct X [--status]` | 步骤、记录、总进度、总览同步更新 | 方案未确认 → 退出码 1；步骤越界 → 退出码 2 |
| F3.9 | 文档复盘 | `review [任务名]` | `docs/specs/<任务>/review.md` 生成，含四份文档指纹与检查结果 | 文档没填完 → 复盘失败（退出码 1） |
| F3.10 | 根目录任务总览 | `plans [--serve]` | `plans.html` 列出任务：点任务名弹窗看详细进度、展开编辑、UI 弹窗预览、对话、删除、重跑 | 未起服务时按钮只复制命令 / 提示词 |

## 4. 复用关系（只在所属域计一次）

| 被复用的能力 | 所属域 | 复用方 | 关系说明 |
|---|---|---|---|
| 任务页校验脚本（含文档一致性） | 任务页与进度 | 校验门禁 | 校验命令调用它，不重复实现规则 |
| 认领校验 | 并行认领 | 校验门禁、项目门禁 | 门禁里跑同一条校验 |
| 入口地图生成 | 初始化与配置 | 校验门禁 | 校验只读结果，不生成 |
| 代码风格判定 | 代码风格与提交 | 交付验收 | 验收时作为一条检查项 |
| 工具自检 | 自检与集成 | 交付验收 | 上线前第一步 |

## 5. 不在本清单内的东西（避免误读）

- 账号、权限、审计、看板、通知：**没有**。
- 远程流水线与部署：**没有**；生成的 CI 骨架需要接客户自己的流水线。
- 业务代码生成：**没有**；只生成工程配置与文档骨架。
