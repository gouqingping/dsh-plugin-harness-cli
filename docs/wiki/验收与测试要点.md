# 验收与测试要点

> 读者：产品、测试。**能照着做**的验收清单：每行写清「怎么算过、什么情况不算失败」。
> 组织方式按**业务场景**，不按页面或技术模块。带「※」的是当前只能人工确认的项。

## 0. 使用方式

1. 按场景顺序执行，不跳步（后一个场景依赖前一个的产出）。
2. 每条都要留下证据：命令、输出摘要、时间、执行人。
3. 「不算失败」列写的是**正常但看起来像故障**的现象，避免误判。

## 场景 A · 环境与安装

| # | 检查项 | 怎么算过 | 什么情况不算失败 |
|---|---|---|---|
| A1 | 运行环境版本 | 版本满足最低要求（≥18） | 版本更高不影响 |
| A2 | 依赖与自检 | 自检 7 项无错误 | 「不是 git 仓库」是警告，不计失败 |
| A3 | 目录可写 | 在目标项目目录能生成文件 | 在其他目录报不可写，只是位置不对 |
| A4 | 风格能力可用 | 风格自检通过 | 本机没有 python3 → 仅该能力不可用，不算整体失败 |
| A5※ | 平台集成 | 平台侧能看到 11 个工具 / 10 条命令，且 `/harness-cli-help` 可用 | 首次安装后未重启平台，暂不出现属正常 |

## 场景 B · 新项目接入

| # | 检查项 | 怎么算过 | 什么情况不算失败 |
|---|---|---|---|
| B1 | 生成骨架 | 输出 CREATE/KEEP 清单，骨架文件齐全 | 二次执行全是 KEEP 属正常（不覆盖） |
| B2 | 启用任务页 | 多出任务页目录、模板、总览页、页面校验脚本 | 已存在文件被 KEEP 属正常 |

| B4 | 首次校验 | 严格模式通过；无红项 | 「项目定位是占位」是警告，按交付要求决定是否清零 |

## 场景 C · 老项目补规范

| # | 检查项 | 怎么算过 | 什么情况不算失败 |
|---|---|---|---|
| C1 | 只补缺失 | 已有非空文件保持原样（KEEP） | 开关被写回配置属正常 |
| C2 | 状态文件不被覆盖 | 进度日志、功能清单、任务队列内容不变 | 即使显式要求覆盖也不变（设计） |
| C3 | 老任务补文档 | 执行建页命令后，缺失的规范文档被补齐，页面不变 | 页面已存在时提示「未改动」属正常 |

## 场景 D · 单任务交付

| # | 检查项 | 怎么算过 | 什么情况不算失败 |
|---|---|---|---|
| D1 | 建任务页 | 页面 + 四份文档 + 总览刷新 | 新建页校验失败（骨架待填）属正常 |
| D2 | 领域段（DDD） | 上下文、≥3 条术语、≥1 聚合、≥1 不变量都有且非占位 | 术语多于 3 条不影响 |
| D3 | 契约段（SDD） | ≥2 条契约，六格齐全，编号唯一且与文档一致 | 契约多于 2 条不影响 |
| D4 | 测试段（TDD） | 每条契约至少一条用例，红/绿标注正确 | 用例多于契约数不影响 |
| D5 | 规划段 | 步骤从 1 连续、每步绑定契约、可增删 | 步骤数与契约数不要求相等 |
| D6 | 进度与记录 | 总进度 = 步骤汇总；末条记录 = 当前汇总；时间递增 | 记录多于必要条数不影响 |
| D7 | 总览一致 | 进行中任务全部出现在总览且数值一致 | 未改状态时总览不变属正常 |
| D8 | 完成判定 | 标「完成」时全部步骤 100% 且无红用例 | 标「待验收」时允许保留验收步 |
| D9 | UI 设计稿 | 跑 `ui` 后生成 `ui/index.html` 与说明；令牌、组件 ≥4、说明三节齐全 | 没有界面需求的任务可不生成（只警告） |
| D10 | 方案确认 | `page` 生成 `plan.html`；`plan --confirm` 后状态为「已确认」且记录确认人与时间 | 待确认状态下推进度会被拒绝（退出码 1） |
| D11 | 进度写入 | `progress --step N --pct X` 后页面、记录、总览三处一致 | 方案未确认时拒绝；重复调用只追加记录，不算失败 |
| D12 | 复盘与定稿 | `review` 生成 review.md 且检查结果无 ❌；确认后改文档 → P22 失败、progress 拒绝 | 只改错别字也需重新复盘（指纹变化），这是设计 |
| D13 | 视图→规格同步 | 改 `ui/index.html` 或 `docs/wiki` 后，跑 `ui` / `wiki` 能把指纹写回 specs，P23/P24 转绿 | 未改视图时 P23/P24 本就通过，不需要额外操作 |
| D14 | 任务总览操作台 | `plans --serve` 后：点任务名弹窗加载 `progress.html`；展开/收起正常；保存并重启、重跑、删除都落盘；UI 弹窗能渲染设计稿；「对话」复制启动提示词 | 以 file:// 打开时按钮只复制命令；「对话」在无宿主钩子时只复制提示词，均不算失败 |

## 一页速查

```
环境 → 生成骨架 → 配置生效 → 首次校验
     → 建任务页 → 填 DDD/SDD/TDD → 推进度 → 校验 → 门禁
     → 并行时认领 → 收工释放
     → 交付前：自检 → 严格校验 → 门禁 → 场景验收 → 回滚演练
```
